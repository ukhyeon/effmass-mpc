# 커밋 규칙 (이 저장소)

## 단계가 끝날 때마다

- 커밋 1개와 태그 1개를 만든다. 태그: `v0.1-static` (V2 까지), 다음은 `v0.2-r1`, `v0.3-r2`, ...
- README 의 현재 단계 표(갱신 날짜 포함), 결과, 대표 영상을 갱신한다.
- `docs/progress.md` 에 단계를 추가한다: 무엇을 확인했나, 핵심 수치, 근거 로그 파일 (한 단계 5줄 이내). 수치는 로그에서 읽는다.

## 넣지 않는 파일 (매번 다시 적용)

- SMPL 모델 파일, 메시 정점이나 SMPL 자세 매개변수가 든 npz (구역 메시 npz, precomputed npz 포함)
- Kinect 녹화에서 나온 모든 사람 데이터
- 타사 코드, 타사 코드를 수정한 파일, 로봇 에셋, USD, 가상환경, cache/, warp 캐시, 프레임 폴더, rec 폴더
- 원본 mp4 중 25 MB 를 넘는 것, 5 MB 를 넘는 로그 json
- 진행 중인 단계의 산출물
- 판단이 필요한 파일(규격 수치 파일 등, 목록에 없는 종류)은 넣지 않고 보고한다

`.gitignore` 는 허용 목록 방식이다. 새 종류의 파일은 `.gitignore` 에 명시적으로 추가해야 들어간다.

## 공개 전 점검 (매번)

넣을 파일 전체에서 찾아 건수와 위치를 확인한다.

- 비밀번호, 토큰, API 키, 로봇 IP, 사설 IP 주소 → 하나라도 나오면 그 파일을 빼고 보고
- 홈 절대 경로와 호스트 이름
- 다른 사람의 이름이나 연락처

## 문서 규칙

- 로그에서 확인하지 못한 수치는 쓰지 않는다.
- 성능을 과장하는 표현을 쓰지 않는다. 비교는 "균일 대 제안, 같은 설정" 으로만 쓴다.
- 비밀번호와 로그인 정보는 어디에도 쓰지 않는다.
