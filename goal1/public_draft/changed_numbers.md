# 바뀌는 숫자 목록 (공개 자료의 기존 숫자 대 새 숫자)

달라진 이유는 두 가지다.

- **(가) 식의 기준 변경:** 이전 식은 모든 부위에 같은 기준 환산질량 0.53 kg 을 썼다. 지금 식은 부위마다 ISO/TS 15066 기준 질량(로봇 질량과 묶은 값)을 기준으로 쓴다. 손은 기준이 비슷해 거의 같고, 아래팔·위팔·몸통·머리는 구역이 얇아진다.
- **(나) 간격을 재는 규칙 변경:** 새 숫자는 세 방식(균일·이전 식·부위별)을 같은 규칙으로 다시 쟀다. 대상은 로봇 구 전체(MPC 반지름 + 0.02 m)와 사람 형상 전체 사이의 간격이고, 경로 양 끝 10 cm(출발·도착 자세 근처)는 뺀다. 기존 README 의 V2 숫자는 손 형상만, 끝을 빼지 않고 잰 값이었다.

"이전 식(새 규칙)" 열은 같은 실행을 새 규칙으로만 다시 잰 값이다. 기존 숫자와 이 열의 차이는 (나) 때문이고, 이 열과 부위별 열의 차이는 (가) 때문이다.
값은 cm, 따로 적지 않으면 seed 0~2 평균이다. 근거: `goal1/part_regen/summary_*.json`, `goal1/part_regen/REPORT.md`.
