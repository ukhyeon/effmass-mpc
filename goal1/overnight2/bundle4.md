# 묶음 4: 안전 장치 (새 옵션, 기본 끔)

## 무엇을 넣었나

- `--safety-near 1`: 매 스텝 현재 관절 상태에서 로봇 구와 사람 형상의 최소 간격 d(표의 간격과 같은 규칙: 구 반지름 + 2 cm 여유)를 잰다. d 가 12 cm 아래면 그 스텝의 관절 명령 이동량을 s = (d - 3 cm) / (12 cm - 3 cm) 배로 줄이고, 3 cm 아래면 현재 자세를 유지한다. 회피 비용과 따로 동작한다.
  - `--safety-allow-retreat 1`(기본): 명령한 관절에서 간격이 줄지 않는 명령(물러나는 명령)은 줄이지 않는다. 0 이면 방향과 관계없이 멈춘다(처음 판).
- `--safety-loss-stop 1`: 사람 자료의 나이가 0.5 s 를 넘으면 현재 자세를 유지한다(지금 실시간 설정은 0.5 s 뒤 사람 비용을 끄는데, 그 대신 멈춤).
- `--human-gap-sim t0,t1`: 시험용. 재생 사람 프레임을 t0 의 것으로 멈춰 사람 추적이 끊긴 상황을 흉내 낸다.
- 기본은 모두 끔. 껐을 때: 기존 실행과 관절 값이 비트 단위로 같다(run3 4992스텝, live3m 5069스텝, V2 기준 실행 2개).

## 해석

- 멈춤판은 "사람과 3 cm 안에서 로봇 속도가 0에 가깝다"를 만족한다(중앙값 0.02~0.03 m/s, 최댓값 0.05~0.06 m/s). 그러나 도착이 15~18 % 줄고(41 -> 35, 22 -> 18), 겹친 스텝은 오히려 늘었다(7 -> 305, 0 -> 1938). 녹화된 사람은 로봇에 반응하지 않아, 멈춘 로봇 쪽으로 팔이 계속 들어왔기 때문이다. 이 겹침은 로봇이 다가가서 생긴 것이 아니다(다가가는 속도 최댓값 0.04~0.05 m/s).
- 물러나기 허용판은 3 cm 안에서 사람 쪽으로 다가가는 속도가 0 이고, 물러나는 움직임만 남는다(그래서 속도 크기는 0.42 m/s). 겹친 스텝 7 -> 5, 도착 41 -> 40, 22 -> 21 로 손해가 거의 없다.
- 이 녹화들에서는 끈 상태에서도 3 cm 안에서 사람 쪽으로 다가가는 속도가 거의 없었다(최대 0.016 m/s). 지금 비용 설계(사람 근처 속도 상한 포함)가 이미 다가가는 움직임을 막고 있어서, 안전 장치는 회피가 실패했을 때의 마지막 보호다.
- 놓침 멈춤은 끊긴 뒤 0.5 s 부터 TCP 속도를 0.46 -> 0.04 m/s(중앙값)로 줄였다. 최댓값 0.4~0.5 m/s 는 멈추기 시작하는 첫 순간의 감속이다.
- 실물에 쓸 때는 물러나기 허용판(기본)을 추천한다. 다만 "3 cm 안에서 어떤 방향으로도 움직이지 않음"이 필요하면 멈춤판(`--safety-allow-retreat 0`)을 쓴다. 어느 쪽을 쓸지는 사용자가 정할 일이다.
