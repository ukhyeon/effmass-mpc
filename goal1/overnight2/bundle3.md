## (나) 60 -> 1000번/초 잇기 모의 시험

입력: 다시 틀기 실행에서 기록된 60번/초 관절 목표(live3m 부위별 seed 0 의 5-35 s, 움직이는 손 0.5 m/s 부위별 seed 0 의 0-30 s). 이 명령 자체는 FR3 한계 안이다(가속도 최대 한계의 0.7배).
전달 조건: 지연 5 / 10 / 20 ms x 도착 시각 흔들림 0 / 5 ms x 빠짐 0 / 5 / 20 % = 18가지, 실행 2개 -> 방법마다 36가지. 한계: FR3 공식 문서(fr3_limits.json).

샘플 수는 1000번/초 샘플 중 어느 한 관절이라도 한계를 넘은 개수의 합(36가지 조건 합계)이다. 토크 변화율은 관절을 강성·감쇠로 따라가게 한 간단한 모의(강성·감쇠는 libfranka 예제 값을 기억으로 쓴 가정값, 관절 관성도 가정값)에서 잰 것이다.

**추천:** 보낸 순서(패킷 번호)로 시각을 정하고 2주기(33 ms) 버퍼를 둔 5차 보간. 지연 20 ms, 흔들림 5 ms, 빠짐 20 % 에서도 속도·저크·토크 변화율 한계를 넘지 않았다. 가속도는 15개 조건에서 최대 1.12배를 넘었으므로 가속도 상한(자르기)을 함께 둔다. 대가로 33~43 ms 의 지연이 더해진다. 지연을 줄여야 하면 1주기 버퍼의 3차 보간(17~27 ms)에 가속도·저크 제한을 더하는 쪽이 다음 후보다. 마지막 값 유지와 직선 보간은 토크 변화율 한계(1000 Nm/s)를 넘으므로 쓰지 않는다.
