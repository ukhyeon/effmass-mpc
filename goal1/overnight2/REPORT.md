## 보류한 문제

- 손끝 앞 통과(동작 1·2)에서는 길을 낮춰도 정지 장면만큼 큰 차이를 보이지 못했다(아래로 기운 손 위로 로봇이 먼저 다가옴). 팔꿈치 앞은 낮춘 길에서 +4.0 cm 가 나왔다.
- sensing 을 켜면 계산 시간이 4.2 % 스텝에서 16.7 ms 를 넘는다. 기본 설정을 바꿀지는 정하지 않았다.
- 토크 변화율 모의의 강성·감쇠·관성은 가정값이다(libfranka 예제 값을 기억으로 씀).

## 아침에 정할 것

1. 공개 초안을 반영하고 push 할지. 영상에 얼굴과 연구실이 나온다(`goal1/public_draft/prepush_check.md`).
2. 실물에서 안전 장치를 멈춤판과 물러나기 허용판 중 어느 쪽으로 쓸지.
3. sensing 과 함께 돌릴 때 MPPI 후보 수·반복 수를 줄일지(넘김 4.2 % → 0 %, 대신 도착 횟수 감소).
4. 60 → 1000번/초 잇기에 5차 보간(+33~43 ms 지연)을 쓸지, 지연이 짧은 3차 보간에 가속도·저크 제한을 더할지.
5. 손끝 앞 통과를 다시 녹화할지. 팔을 수평으로 뻗고, 로봇 길과 높이를 미리 정한 채 녹화하면 차이가 더 분명할 것이다.
